# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Technical recruiters, engineering hiring managers, and tech leads evaluating candidate capability for Full-Stack and Frontend software engineering roles.

## Product Purpose
A sleek personal developer portfolio for Bhavesh Patil designed to showcase real production-ready web applications, technical skill depth, and direct contact options.

## Positioning
Demonstrates full-stack craftsmanship: high-precision frontend execution (React, Next.js, Tailwind CSS) paired with real backend architectures (Node.js, PostgreSQL, MongoDB, Prisma ORM, Supabase, JWT Authentication).

## Operating Context
Fast recruiter scans (<30 seconds), in-depth technical evaluations of GitHub code and live demos, viewed across desktop and mobile browsers.

## Capabilities and Constraints
- High-performance Next.js 16 (App Router) application.
- Seamless Dark and Light theme adaptation.
- Curated project showcases with live demo and GitHub source links.
- Single source of truth for portfolio content in `lib/data.ts`.

## Brand Commitments
- Identity: Bhavesh Patil (@BhaveshP888).
- Voice & Tone: Confident, minimal, craft-first, authentic.
- Visual Standards: Restrained elegance, high-contrast typography, and fluid micro-interactions.

## Evidence on Hand
- Live full-stack projects:
  - **Logitrack**: `https://logitrack-beta.vercel.app` (Source: `https://github.com/BhaveshP888/logitrack`)
  - **DecodeAi**: `https://decode-dusky.vercel.app/` (Source: `https://github.com/BhaveshP888/Decode`)
- High-resolution preview assets in `public/` (`logitrack_hero.png`, `decodeai_hero.png`).

## Product Principles
1. **Proof Over Promises**: Lead with working products, real code, and verifiable engineering architecture.
2. **Restraint & Craft**: Avoid generic AI design tropes; prioritize typography, spacing, and subtle tactile physics.
3. **Frictionless Navigation**: Ensure instant access to live demos, code, resume, and direct communication channels.
